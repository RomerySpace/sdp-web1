# south-court / south
ID: `south-court-south`. Formato: poster. Tamaño: 1.4 × 2 m.

Coloca aquí `poster.webp` o `screen.mp4`, y añade `image` o `video` en `/public/ads/slots.json` con la ruta `/ads/south-court/south/...`.

La superficie solo se monta si encuentra pared plana completa (sin puertas). Consulta `placements` en el diagnóstico del shooter para conocer las superficies montadas.
